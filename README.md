# Nehir-TicTacToe 

Modern ve şık bir arayüze sahip, yapay zeka destekli web tabanlı **Tic Tac Toe (XOX)** oyunu. HTML5, CSS3 ve Vanilla JavaScript kullanılarak geliştirilmiştir.

## Özellikler

* **Giriş Ekranı:** Oyuna başlamadan önce kendi adınızı girebilir ve kişiselleştirilmiş bir deneyim yaşayabilirsiniz.
* **Yapay Zeka (Bot) Desteği:** Bilgisayara karşı tek başınıza oynayabilirsiniz.
* **Zorluk Seviyeleri:**
  * **Kolay:** Rastgele hamleler yapan başlangıç seviyesi.
  * **Orta:** Kazanmayı ve engellemeyi bilen akıllı seviye.
  * **Çok Zor (Yenilmez):** **Minimax algoritması** kullanan, yenilmesi imkansız profesyonel mod!
* **Skor Tablosu:** Galibiyetlerinizi, beraberlikleri ve bilgisayarın skorlarını anlık olarak takip edebilirsiniz.
* **Açık Mavi Modern Tema:** Göz yormayan, estetik degrade arka plan ve şık arayüz tasarımı.

## Teknolojiler

Proje tamamen saf web teknolojileriyle sıfırdan yazılmıştır:
* **HTML5** - Sayfa yapısı ve iskeleti
* **CSS3** - Tasarım, renk paletleri, esnek düzen (Flexbox/Grid)
* **JavaScript (ES6+)** - Oyun mantığı, DOM manipülasyonu ve Minimax yapay zeka algoritması

## Nasıl Çalıştırılır?

Projeyi bilgisayarınızda çalıştırmak veya GitHub Pages ile internete yüklemek oldukça basittir:

1. Bu repository'yi bilgisayarınıza indirin veya klonlayın.
2. Klasörün içinde şu üç dosyanın bulunduğundan emin olun:
   * `index.html`
   * `style.css`
   * `script.js`
3.  Oyunu oynamak için [buraya tıklayabilirsiniz](https://tic-tac-toe-nehir.netlify.app/).
